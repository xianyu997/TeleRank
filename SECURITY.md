# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public issue.**

Instead, report it privately via [GitHub Security Advisories](https://github.com/xianyu997/TeleRank/security/advisories/new).

We will investigate and release a fix as soon as possible.

## Scope

- API key or token exposure
- Unauthorized file access
- Remote code execution
- Cross-site scripting (XSS)
- Data leakage between sessions

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅ |
