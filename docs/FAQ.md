# 常见问题

## 为什么有些消息只有频道入口，没有精确消息链接？

Telegram Desktop 导出的 HTML 不一定包含公开频道地址。软件只有在能确认“当前频道 + 当前消息 ID”时，才会生成精确消息链接。

如果导出里没有这个信息，软件会使用导出内容里最像频道入口的邀请链接或加入链接。

## 为什么不直接打开 Telegram App？

直接打开 `t.me` 链接时，Windows 和浏览器可能会跳到 Telegram App 的中间确认页。当前设计是先复制链接，再打开 Telegram Web 收藏页，减少不必要的跳转流程。

## 为什么要保存到 D 盘？

Telegram 导出的文件夹通常以日期命名，不方便区分。软件会按频道名称整理到：

```text
D:\TelegramReactionRanker\Imports
```

这样后续可以在导入历史里直接识别频道。

## 图片和消息会不会乱匹配？

不会按文件夹里的图片顺序硬凑。软件会读取 Telegram 导出 HTML 里的消息结构，把同一条消息里的图片和消息内容绑定在一起。

## 导入很慢怎么办？

第一次导入大量图片时需要扫描文件并建立本地索引。后续从历史导入会快一些。源码里已经使用本地文件索引、虚拟列表和懒加载来减少页面渲染压力。
